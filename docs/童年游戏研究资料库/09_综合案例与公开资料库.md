# 综合案例与公开资料库

整理日期：2026-11-23｜对应 Q03 及全部游戏

## 原始问题与结论

Q03：“有关90年代中原地区的很多游戏，有没有系统化电子游戏的案例或者公开库。”

有民间游戏合集、怀旧校园案例、规则数据库和开源棋牌合集；尚未确认一套完整覆盖本资料库八类、明确按 90 年代中原地方规则实现且许可清楚的工程。
“在中原玩过”“跨地区同类”“专门记录中原规则”是不同证据，地域和年代不能由美术氛围推断。

## 最值得阅读的合集源码

[AloysHF/childhood README](https://github.com/AloysHF/childhood/blob/master/README.md)与仓库许可已复核。项目使用网页技术，公共目录列出 card-game-core.js、webrtc-connection.js、network-game-protocol.js、room-ui.js；适合参考规则模块、房间和输入组织。README 提供 npm install、浏览器打开 index.html 或 npx serve 的运行方式；这些命令本轮未执行，联网质量未验证。

[Just-Artur0/Just-Games](https://github.com/Just-Artur0/Just-Games)为 Python／Pygame 公开代码。作者称其开源，但本轮元数据未识别项目许可证，发布页又说明使用剧集素材。因此保留为代码结构参考，不能当作已确认可商用的资产包。
**历史状态修订：**早期回答称提供 Android 下载；本轮作者页面写 Android port in development，并建议手机用网页入口。当前不能概括为成熟 Android 版。

## 面向后续开发的使用顺序（建议）

1. 用用户口述确定地方版本，给规则版本命名；保留来源与尚不确定的细则。
2. 先研究直接对应案例的输入与判定，再看合集菜单、进度和多人结构。
3. 将现实规则与屏幕化适配分别记录，例如动作选择、时机窗口和数值平衡条。
4. 拷贝代码前核定具体版本的 LICENSE、第三方依赖与素材；当前未定引擎、联网方式或商用范围。

仅新增通用引擎并不能填补动作规则缺口。本资料库的价值是把规则、案例和实现差异对应起来，而不是声称找到现成的完整产品。
