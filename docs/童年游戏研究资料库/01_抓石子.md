# 抓石子：规则与电子化参考

整理日期：2026-11-23｜对应 Q01、Q05｜用户地方版本尚未确认

## 原始需求

用户要求按童年现实玩法介绍规则，并寻找 PC／移动端同类和公开库。Q05 原文：“童年玩过 抓石子游戏，介绍一下规则。然后根据规则，在网上寻找电子化的同类或者相似玩法。电脑或者移动端都行，最好有公开库可以参考”。

## 现实规则与变体

常见五颗版使用圆滑小石子或小沙包，平地或桌面即可；可独练，也可多人轮流。核心循环是抛起一颗，在落下前抓取地上指定数量，再用同一只手接住抛子。[五石子玩法指南](https://montfortcare.org.sg/wp-content/uploads/2025/11/01-Five-Stones.pdf)

| 阶段 | 常见目标 | 需要另定的地方规则 |
|---|---|---|
| 抓一 | 每次抓一颗，四次抓完 | 是否可以重选抛子 |
| 抓二 | 每次抓两颗，两次抓完 | 是否允许碰动非目标石子 |
| 抓三 | 三颗＋一颗 | 三加一还是一加三 |
| 抓四 | 一次抓四颗 | 是否先在抛接中放下四颗 |
| 背子／翻背 | 手心抛起，手背接，再抛起翻手抓回 | 按接住数计分还是必须全接 |

漏接、掉子、抓取数量错误通常结束本次机会；碰动其他石子是否违规、失败后重来哪一关，应由版本确定。胜负可按先通关或累计分数，不混用。上表为常见玩法的整理，并非全部由同一指南规定；翻背可对照 [Gonggi 分阶段说明](https://ormgames.com/en/gonggi/)。Gonggi、Korean Jacks、Five Stones 是检索同类的关键词，不等于本地规则完全相同。

## 源码、运行与许可

优先阅读 [yunjinkyu/Gonggi 的 index.html](https://github.com/yunjinkyu/Gonggi/blob/main/index.html)。可检索 STAGE_CONFIG、getTargetZone、rollStage5Count、animateStandardTurn。静态代码显示按松手值是否落入区间判断成功，翻背数量有随机计算。联机代码存在不代表联机已验证。

仓库未识别到明确许可证，应记为“公开源码，复用许可待核定”。本轮未安装依赖、运行网页或验证远程依赖。其余商店项目也未找到可确认授权的游戏主体源码。

## 开发参考（建议）

保留“有限滞空时间内选择哪几颗、移动取子、及时回手接抛子”的连续决策。
建议规则状态拆为：撒子→选抛子→抛起→收集→接取→判定→下一阶段／换人。
可配置数量组合、抛物时长、触碰容忍、失败续关方式、翻背计分；不要把随机动画误作真实手部物理。
第一版可用鼠标／触屏选石，后续再增加自由手部控制；具体引擎未决定。
