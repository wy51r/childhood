# 跳房子：规则与电子化参考

整理日期：2026-11-23｜对应 Q01｜尚无用户提供的具体格图

## 原始需求

最初四类童年游戏之一。需保留投石、跳格、单／双脚、返程取石和失误换人，而不只是一个连续跳跃小游戏。

## 现实规则与变体

场地可用粉笔或地面划格，通常配一枚小石片／沙包，单人练习或多人轮流。以下采用“投物—避格—返程取物”的常见版本：

1. 给房子格编号，确定单格、并排双格与转身区。
2. 从起点向本轮目标格投标记物，投错格或压线则换人。
3. 跳过放有标记物的格子；单格单脚，并排双格可双脚分别落入。
4. 到末端转身返回，在邻格保持平衡并弯腰拾取标记物，再跳回起点。
5. 成功后目标格递进，按约定轮换；先完成全部目标者获胜。
6. 踩线、落在不允许的格子、单脚阶段另一脚着地或失衡，通常失去本次机会。

依据：[Playworks Hopscotch](https://www.playworks.org/game-library/hopscotch/)。这一来源提供通用对照，不证明它就是用户所在地区的版本。
踢石子推进、买房／占格、盘旋图、八格／十格等应独立记录，不能在一局中默认混合。[多伦多市规则变体资料](https://www.toronto.ca/community-people/health-wellness-care/health-programs-advice/physical-activity/outdoors-the-ultimate-playground/games/go-play-hopscotch/)

## 开发参考（建议）

将格图存成可配置节点，标记邻接关系、允许脚型、可否停留和返程路线。状态流程可为：
投掷→检查落点→去程跳格→转身→返程拾物→结算。
投掷落点和落脚位置是两个判定；动作正确但踩线仍可失败。单脚平衡可先简化为短暂保持输入或时机判定，但要明确这是电子化适配。
