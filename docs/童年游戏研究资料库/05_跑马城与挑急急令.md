# 两队牵手冲撞：跑马城／挑急急令

整理日期：2026-11-23｜对应 Q02｜名称匹配来自资料，用户所在地名称未确认

## 用户原始描述

“还有一种是A/B两队，手拉手站好，某一对跳一个人，来撞自己的队伍，撞开跳一个人对自己对，撞不开留下。”

保留原句中的笔误。当前整理理解为：双方牵手成排，一名队员冲撞对方，撞开后带走一人，撞不开则加入对方。谁有权点人、成功后能选谁，仍需明确。

## 名称与现实规则

[北京日报《老北京的“马上游戏”》](https://xinwen.bjd.com.cn/content/s69ca4224e4b0cd719e9fbdc6.html)将跑马城与挑急急令对应，描述点将冲撞与成功带人、失败扣留；[中原民间游戏目录](https://fy.szu.edu.cn/fyxm/xmlb/yxl/zymjyx.htm)列有挑急急令。英文 Red Rover 可作为同类检索。

当前工作版本：

1. A、B 两队手拉手站成两排，先约定间距、边界与轮次。
2. A 队从 B 队点一人，该人冲撞 A 队相邻两人的连接。
3. 成功断开：冲撞者回 B 队，并带走 A 队一人。
4. 未断开：冲撞者加入 A 队。
5. 换边继续；一队人数不足以维持游戏或达到约定条件时结束。

第 2、5 条是结合历史回答和资料的整理，不能替代用户确认；总人数、是否必须从被撞开的两人中选择、站位能否重排属于变体。“撞麻城”作为历史回答中的别名线索保留，未在本轮核定地域对应。

## 公开代码、入口与许可

已复核 [roster.cpp](https://github.com/erik-slack/Red-Rover/blob/master/roster.cpp)，其判定依据为进攻者力量＋速度，与两名相邻防守者力量之和比较，并据结果调整队员归属。带走对象的选择逻辑不完全等于任意挑人。

[README](https://github.com/erik-slack/Red-Rover/blob/master/README.md)说明数据结构为双向链表，并列有待修内存问题。没有明确 LICENSE；没有验证编译命令、编译器或运行结果，故只建议研究回合和队伍逻辑。正式接入前应重写或审查内存管理并核定许可。

## 开发参考（建议）

保留“人墙拓扑”和人数变化，别把它简化为撞倒障碍即过关。
建议状态：点名→选择冲撞连接→助跑／防守准备→判定断链→转队→重新站位→交换回合。
最小版本可先用数值与操作时机决定断链，再加角色物理。力量公式只是该源码的抽象，不是民间规则。

## 待确认与核验

点名权、冲撞目标选择权、能带走谁、同一人能否连续出战、是否允许整队移动、结束人数和站位重排都需补充。
名称规则为 L1；C++ 核心为 L2；图形原型未试玩，无 L3。
