# 待确认、待试玩与历史结论修订

整理日期：2026-11-23。这是后续研究清单，不是本次交付未完成项；资料整理已经覆盖八类游戏及综合资源。用户无需现在逐条回答。

## 开发前优先确认的地方规则

| 优先级 | 游戏 | 需要补充的资料 | 影响 |
|---|---|---|---|
| P1 | 全部 | 具体县市／学校、约哪几年、与谁玩 | 区分中原地方版本和泛童年版本 |
| P1 | 抓石子 | 颗数、抓四步骤、背子计分、失败续关 | 决定关卡和轮换 |
| P1 | 跳房子 | 一张格图、投石或踢石、占房规则 | 决定地图和合法脚位 |
| P1 | 斗拐 | 抱腿方式、触地部位、出界、换腿、双倒 | 决定物理裁判 |
| P1 | 跳皮筋 | 一套完整口诀与动作、高度、宽度 | 决定动作序列而非单纯跳高 |
| P1 | 跑马城 | 谁点名、成功能带谁、何时结束 | 决定回合与人数变化 |
| P1 | 翻花绳 | 起手到后续花样的步骤与上下穿法 | 决定绳圈拓扑和交接 |
| P1 | 木头人 | 原地／接近、能否笑、处罚、摸到后是否追跑 | 决定主循环 |
| P1 | 老狼 | 跟随／按步数、触发口令、安全区、换狼 | 决定问答和追捕循环 |

## 当前证据边界

- 所有项目均未在本次整理中安装、运行或联网对战，没有 L3 结果。
- GitHub 主分支链接会变化，本资料库未保存第三方源码快照；确定采用某项目时，应记录具体提交版本并重新检查 LICENSE。
- 商店可访问不等于在用户地区／设备上能安装。
- 未找到源码不等于全球不存在；“未见许可证”不等于绝对没有任何授权文件。
- 不同名称可能对应不同游戏，需以动作与胜负闭环核对。
- 没有明确为第三方图片、音乐、商标授权；文档保留链接与研究摘要，不打包这些资产。
