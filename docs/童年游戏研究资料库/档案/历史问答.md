## Q01 · 2026-11-11（UTC 日期）

### 用户原始问题

儿童游戏：抓石子、跳房子、斗拐、跳皮筋。有没有专门把这种类型的游戏电子化的游戏。所有的玩法和设计参考现实玩法，但是在PC或者手机上可以玩。有没有同类的游戏或者空开库，帮我搜寻一下

### 当时的回答

**有，这类“把现实童年游戏搬到屏幕上”的作品确实存在，但比较分散。**这次找到抓石子、跳房子、跳皮筋的对应作品，以及有源码的传统游戏合集；**还没找到把你列的四种玩法全部忠实还原、集中在一起的成熟产品。**斗拐的直接电子化版本尤其难找。

我把“空开库”按“开源库／公开源码仓库”理解。下面是筛选后的结果，已核对游戏页面和部分源码，未逐一安装试玩。

如果只想先看一个最符合想法的例子，**先打开 ormgames 的 Gonggi**。它比较清楚地展示了：怎样用点击、拖动和接取时机，保留现实游戏的操作顺序与失误规则。

**公开源码：有可研究的项目，但没找到成熟的“四种玩法开源库”**

目前比较值得看的，是 **[Just-Artur0 / Just-Games](https://github.com/Just-Artur0/Just-Games)**：

我也排除了几个很容易误选的仓库：

- [hwlvipone/gonggi-game](https://github.com/hwlvipone/gonggi-game)：实际是介绍抓石子规则与历史的网站，**没有实现抓石子游戏**。
- [kliaw1/HopscotchMiniGame](https://github.com/kliaw1/HopscotchMiniGame)：源码实际是掷骰、抽卡、消耗货币走格子，**不符合现实跳房子的玩法**。

**针对你的四种玩法，我的判断是：**

- **抓石子：**已经有很直接的电子化参考，最适合先研究。
- **跳房子：**有对应手机游戏，但还需要试玩确认投石、避格、返程拾石等规则保留到什么程度。
- **跳皮筋：**有老网页案例和合集原型，现代完整复刻的选择较少。
- **斗拐：**这次没有检索到可确认的、还原“单腿支撑、膝部对抗、失衡落地判负”的 PC／手机成品或源码项目；这不代表完全不存在。

**如果你是在为开发自己的游戏找参考，我建议以 Gonggi 的规则还原为标准，以 Just Games 的合集结构为参考。**本轮还没有找到能够直接拿来改造、同时覆盖这四项玩法且许可明确的完整工程。


## Q02 · 2026-11-11（UTC 日期）

### 用户原始问题

所选文字：还原“单腿支撑、膝部对抗、失衡落地判负”。

确实是这跟规则。还有一种是A/B两队，手拉手站好，某一对跳一个人，来撞自己的队伍，撞开跳一个人对自己对，撞不开留下。这个游戏也帮我搜寻一下。

### 当时的回答

[针对用户选中文字的回应] 明白，斗拐就是你确认的“单腿支撑、膝部对抗、失衡落地判负”。

**你新描述的游戏找到了：国内叫“跑马城”，也称“挑急急令”；有些地方有“撞麻城”等叫法。英文里对应的同类玩法叫 Red Rover。**《北京日报》对跑马城的描述，正是两队拉手、点名冲撞，冲破后带走对方一人，失败则留在对方队伍。[名称与规则来源](https://xinwen.bjd.com.cn/content/s69ca4224e4b0cd719e9fbdc6.html)

按你的版本，可以准确记成：

1. A、B 两队分别手拉手，面对面站成一排。
2. A 队从 B 队点一个人，让他来冲撞 A 队的人墙。
3. 撞开：冲撞者从 A 队带走一人，回到 B 队。
4. 撞不开：冲撞者留下，加入 A 队。
5. 双方轮流，直到一队人数不足以继续。

**电子版和源码方面，这次找到三个有参考价值的结果：**

| 项目 | 平台／形式 | 与你描述的符合程度 |
|---|---|---|
| **[Red Rover — AmandaCaswell](https://amandacaswell.itch.io/red-rover)** | 网页技术制作的小型原型，当前页面提供下载 | 作者明确以童年 Red Rover 为原型，方向键移动、空格加速，冲破人墙。但**没有核实是否完整实现交换队员和两队轮换**。[作者介绍](https://www.tomsguide.com/ai/its-no-fortnite-but-i-just-created-a-game-using-grok-heres-how) |
| **[Red Rover Run: Merge & Attack](https://play.google.com/store/apps/details?id=red.rover.run.attack)** | Android | 保留了加速、增强力量、冲破成排人物的表现，但加入合成升级和跑酷闸门，**属于改编，和你的原始规则差别较大** |
| **[erik-slack / Red-Rover](https://github.com/erik-slack/Red-Rover)** | C++ 公开源码，文字界面 | **规则逻辑最接近。**有两队、选择冲撞者、选择两名相邻防守者之间的连接、成功带人回队、失败加入对方、交替回合和人数判胜 |

其中，**第三个源码项目最值得研究**。我查看了它的实际代码，冲撞结果通过下面的数值比较决定：

> 进攻者力量＋速度 ＞ 两名防守者力量之和 → 冲破。

它保留了“冲撞改变队伍人数”的核心逻辑，但没有人物奔跑、拉手和碰撞动画；成功带谁走的设计也不完全等同于你说的自由挑人。README 标注存在内存问题，仓库没有明确的 LICENSE，因此目前适合做规则与代码结构参考，不能直接当成成熟可复用的开源成品。[核心实现](https://github.com/erik-slack/Red-Rover/blob/master/roster.cpp)

**目前的搜索结论：这项游戏有电子化原型，也有接近原规则的公开源码；但还没找到能确认完整还原你这套规则、带图形操作的成熟 PC／手机游戏。**后续检索可用：`跑马城`、`挑急急令`、`撞麻城`、`Red Rover playground game`。单搜 Red Rover 会混入大量同名火星车游戏。

## Q04 · 2026-11-23（UTC 日期）

### 用户原始问题

童年玩过翻花绳游戏，介绍一下规则。然后根据规则，在网上寻找电子化的同类或者相似玩法。电脑或者移动端都行，最好有公开库可以参考

### 当时的回答

**有相关电子化案例，也有可参考的开源项目；但本次没有找到完整还原“双人轮流接绳、连续翻出花样”的成熟开源游戏。** 找到的项目分别实现了手势互动、绳形解谜或教学，下面把差别说清楚。

**翻花绳的基本规则**

翻花绳用的是一根首尾相接的绳圈，主要有两种玩法：

- **单人造型**：通过手指挑、勾、穿、绕、放绳，翻出梯子、网、动物等图案，重点在于记住动作顺序和完成造型。
- **双人接绳**：两个人轮流从对方手上接过绳圈，每接一次，形成一个新的图案。你童年熟悉的，很可能就是这一种。

双人玩法通常这样进行：

1. **起手**：A 把绳圈套在双手上，用手指撑出初始图案。
2. **挑绳**：B 观察绳段和交叉点，用手指挑住指定位置，再从上方或下方穿过其他绳段。
3. **交接**：B 接稳后，A 撤出双手；B 向两侧撑开，形成新图案。
4. **轮换**：A 再从 B 手上接回来，继续变化。
5. **结束或判负**：接错、散掉、打成无法继续的结，或不会下一步时结束；也可以合作，看能连续完成多少次。

不同地方的花样名称、顺序和输赢约定会有差别，不能把某一种固定流程当成唯一规则。其核心是**保持同一个绳圈，通过接绳改变绳段的交叉关系和手指支撑位置**。[双人玩法图解参考：Maple Ridge Museum](https://mapleridgemuseum.org/wp-content/uploads/2025/01/Craft-Create-Cats-Cradle.pdf)

**网上找到的电子化案例**

| 项目 | 平台及玩法 | 与真实翻花绳的关系 | 源码情况 |
|---|---|---|---|
| **Cat’s Cradle — Interactive String Art** | 浏览器＋摄像头，识别双手，在手指之间显示动态“绳线” | 接近双手撑绳的视觉体验，但没有完整接绳规则 | **MIT 开源** |
| **《扭动的绳子》，原名《愁丝》** | 曾推出 Android／iOS 版；拉扯、扭动绳子，以较少步数变成目标形状 | 开发者明确说灵感来自童年翻花绳，改成了单人解谜 | 未找到公开源码 |
| **Untangle** | 网页、Windows 等；拖动节点，让连线不再交叉 | 可参考“观察交叉关系、移动支点”的解谜玩法，但没有手指接绳 | **MIT 开源** |
| **String Figures made easier** | iOS／Android；用视频、文字和语音控制教学 | 教你拿真实绳子完成花样，并非在屏幕里操作虚拟绳子 | 未确认开源 |

各项目的入口和参考价值如下。

**1. 最适合参考手势交互：Cat’s Cradle**

[在线演示](https://afnan-nex.github.io/cats-cradle/index.html) · [GitHub 源码](https://github.com/afnan-nex/cats-cradle)

它使用 JavaScript、Canvas 和 MediaPipe 手部识别。打开网页、允许摄像头后，移动双手就能改变画面中的线条。

我进一步检查了[实现代码](https://github.com/afnan-nex/cats-cradle/blob/main/index.html)：它主要按照预设方式连接手部关键点，再绘制曲线和发光效果。**代码没有实现真实闭合绳圈、勾住／脱离绳段、双人交接和花样判定。**

因此，它很适合参考“怎样识别手指、怎样画出跟手移动的线”，不能直接当作完整翻花绳游戏使用。

**2. 最值得研究玩法改编：《扭动的绳子》**

[游戏介绍](https://www.taptap.cn/app/47924) · [开发者关于灵感及下架的说明](https://www.taptap.cn/moment/15228686907212145)

它把翻花绳改成了“**当前绳形 → 拉扯变形 → 达成目标绳形**”的关卡游戏。开发者在说明中明确提到，玩法的参考来源就是小时候玩的翻花绳。

这是本次找到的、与你想法关联最直接的成品案例。不过，它属于历史项目：开发者在 2017 年说明停止 Android 公开下载及后续更新；**目前能否从官方渠道安装，我没有确认到**。

**3. 最适合参考完整解谜代码：Untangle**

[直接玩网页版](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/js/untangle.html) · [官方源码及下载入口](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/)

规则非常清楚：拖动节点，直到所有连线都不交叉。它属于 Simon Tatham 的开源益智游戏合集，采用 MIT 许可证。

它可以供你参考：

- 鼠标或触摸拖动支点；
- 线段交叉检测；
- 关卡生成、完成判定和撤销操作。

但要注意，**翻花绳中的交叉往往正是花样的组成部分；Untangle 的目标则是消除交叉**，二者不能直接套用同一套判定规则。[官方规则](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/untangle.html)

**还有两类更贴近真实规则的资料**

- **图案和操作资料：国际翻绳协会 ISFA。** 可查找花样、教学和相关研究；其[软件页面](https://isfa.org/software.htm)还收录了 **String Figure Analyser**，用于分析绳形交叉关系，以及上述手机教学应用。Analyser 提供程序下载，但页面没有明确提供源码，不能算已确认的开源库。
- **真实绳形仿真研究：**《[String Figure Simulation with Multiresolution Wire Model](https://doi.org/10.1145/3587828.3587839)》（2023）研究手指勾住、释放绳圈之后，如何考虑张力和摩擦得到新的绳形。它比普通手势连线演示更贴近真实翻花绳，但本次没有找到配套公开代码。[论文摘要收录](https://www.algoryx.se/publications/)

如果你准备把它加入“童年游戏合集”，我的建议是：**先参考《扭动的绳子》的关卡设计、Untangle 的交互代码，再用 ISFA 的真实花样做内容依据。** 第一版可以让玩家点击绳段，选择“上挑／下穿／接过”等动作，完成正确接绳后展示下一花样；这样能先保留真实规则，再逐步增加自由手势和绳子物理效果。

**有，而且抓石子的电子化案例比翻花绳更直接：找到了网页游戏、Android 游戏、Steam 项目，以及一份可查看的游戏源码。** 不过，公开源码的那个项目把操作简化成了时机判定，和现实中的自由抓取仍有差别。

先按常见的“五颗石子版”介绍规则；中原各地的关卡名称、附加动作和计分方式可能不同。

**抓石子的基本规则**

准备五颗大小合适、比较圆滑的石子，在平地或桌面上玩。核心动作是：

**抛起一颗 → 趁它在空中抓起指定数量的石子 → 用同一只手接住抛起的那颗。**

通常按下面的顺序过关：

| 阶段 | 常见玩法 |
|---|---|
| 抓一 | 撒开五颗，选一颗作为抛子；每次抛起后抓地上的一颗，连续四次 |
| 抓二 | 每次抓两颗，分两次抓完 |
| 抓三 | 分成“三颗＋一颗”抓完，有些地方允许先一后三 |
| 抓四 | 一次抓起地上的四颗；有些版本还要求先在一次抛接中把四颗放下 |
| 翻背／背子 | 把石子从手心抛起，用手背接，再抛起翻手抓住；按接住数量计分，或要求全部接住 |

没接住抛子、抓取数量不对、手里的石子掉落，通常就换人；较严格的版本还规定不能碰动本次不该抓的石子。胜负可以按先过完全部关卡，也可以按背子累计得分。不同地区会增加额外花样，不能把“五关版”当成唯一规则。[五石子玩法指南](https://montfortcare.org.sg/wp-content/uploads/2025/11/01-Five-Stones.pdf)、[分阶段规则参考](https://istanbul.meb.gov.tr/meb_iys_dosyalar/2019_12/05103521_2-_GUIDE_FOR_PARENTS.pdf)

搜索电子版时，**Gonggi、Korean Jacks、Five Stones** 是有效关键词。其中 Gonggi 是韩国的同类玩法，基本抛接动作很接近，但地方规则不一定与你童年玩的完全一致。

**最值得看的三个电子版**

| 项目 | 平台 | 保留的核心玩法 | 源码情况 |
|---|---|---|---|
| **Gonggi — JustACardboardBox** | 电脑浏览器 | 鼠标操作抛石子、抓地上的石子、接住空中石子 | 未找到公开源码 |
| **Starz Stones: Five Stones Game** | Android | 点击抛起，点击或滑动抓取，再按时接住；有五石子分阶段玩法 | 未找到公开源码 |
| **Gonggi: Recess** | Windows／Steam | 鼠标控制手，撒、抛、抓、接；提供练习和对战 | 未找到游戏主体源码 |

[打开游戏：Gonggi by JustACardboardBox](https://justacardboardbox.itch.io/gonggi)

这是本次找到最适合先体验的案例。作者明确列出了抓一、抓二、抓三等五轮流程，还提供不同重力和抛掷条件的场景。

需要注意两点：

**2. 想参考手机触屏操作：Starz Stones**

[Google Play 页面](https://play.google.com/store/apps/details?id=com.starzstech.starzstones)

它把现实动作拆得很清楚：

1. 点击手里的石子，把它抛起来。
2. 在空中停留期间，点击或滑过地上的石子。
3. 等接取提示圈变绿，再点击接住。

过早、过晚或抓取数量不足都会失误。经典模式包含“一颗一颗、两颗两颗、三加一、一次四颗”等阶段，还扩展了七颗、九颗和按颜色抓取的模式。

**3. 想参考“童年游戏＋校园场景”：Gonggi: Recess**

[Steam 商店页面](https://store.steampowered.com/app/5475700/Gonggi_Recess/)

- 从抓一到翻背都有对应阶段；

**这款尤其贴近你之前想找的“系统化童年游戏”案例。** 但状态要说清：截至本次查询，2026 年 11 月 23 日，页面仍显示“即将推出抢先体验”，不能当作已经确认可购买试玩的成品。

- 单人、本地双人和在线对战相关逻辑；
- 分数、轮次、失败处理和速度设置。

**关键差别是：它主要让玩家在进度条的目标区间松手，随后自动播放抓取动画。** 代码没有让玩家自由选择、逐颗抓取地上的石子；翻背接住几颗还使用了随机概率。因此，更适合参考关卡流程、三维表现和对战结构，不能当作真实动作仿真。

仓库目前没有看到明确的 `LICENSE`，应称为**公开源码项目，尚未确认开源授权**。此外，我没有运行它来验证联机稳定性。

如果你的目的是做“90 年代童年游戏合集”，建议优先看 **Gonggi 网页版的抛接操作、Starz Stones 的触屏设计、Gonggi: Recess 的校园组织方式**；代码方面再参考上述仓库的阶段结构。抓石子最值得保留的体验是：**在有限滞空时间内，判断先抓哪几颗、移动多远，以及什么时候收手接住抛子。**

### 用户原始问题

童年玩过 跳皮筋游戏，介绍一下规则。然后根据规则，在网上寻找电子化的同类或者相似玩法。电脑或者移动端都行，最好有公开库可以参考

### 当时的回答

**找到了直接以跳皮筋为主题的电子版，也找到了公开代码。最值得看的是 Arcforge 的《Elastic Jump》；但它把真实动作简化成了四种落脚位置的节奏游戏。** 另外还有“逐级升高皮筋、控制角色跳过”的 Unity 原型。

先介绍现实规则，再对照这些项目的还原程度。

**跳皮筋的常见规则**

跳皮筋各地的套路差别很大。你童年玩的通常属于“**按动作顺序跳完一套，再升高皮筋继续挑战**”的玩法。

1. **撑皮筋**：将皮筋首尾连接成环，两个人面对面站立，用双腿撑开，形成两条平行的皮筋；其他人轮流跳。人多也可以分队。
2. **约定套路**：提前确定动作顺序，可以配合童谣。动作包括跳进、跳出、跨过、踩筋、勾筋、绕筋、转身、脱出等。
3. **逐级升级**：从脚踝附近开始，完成一套后升到小腿、膝盖、腰等高度。具体分几级、每级叫什么，由当地玩法决定。
4. **失误换人**：跳错顺序、漏动作、该勾时没勾住、该踩时没踩准，或者违反约定使用手辅助，通常算失败。
5. **比较成绩**：看谁完成更高等级、更难套路；分队玩法中，有些地方允许跳得好的队友再跳一遍，把失误的人“救回来”。[现实玩法与基本动作](https://www.yp.gov.cn/contents/2021/04/26/yp-115135.html)、[国家体育总局介绍的分队与救人玩法](https://www.sport.gov.cn/n20001280/n20745751/n20767277/c21383785/content.html)

**这里最容易被误解的一点是：碰到皮筋不一定失败。** 很多套路本来就要求踩住、勾住或绕住皮筋；是否犯规，要看当前动作要求。除了升高，有些玩法还会缩小两条皮筋之间的距离，增加落脚难度。[国家体育总局资料](https://www.sport.gov.cn/n20001280/n20745751/n20767277/c21383785/content.html)

| **Chinese Garter — Unity 原型** | Android，仓库含 APK | 左右移动、跳过皮筋，三档高度 | Unity 工程和 C# 代码公开；未见明确许可证 |

**1. 最接近“成套动作＋升高”：Elastic Jump**

[项目介绍](https://equalinformation.com/world-heritage-games-site/games/6-elastic-jump/) · [网页预览入口](https://bpupadhyaya.github.io/games-site/games/elastic-jump/play/) · [Android 合集](https://play.google.com/store/apps/details?id=com.equalinformation.arcforge.shell) · [预览代码](https://github.com/bpupadhyaya/games-site/tree/main/games/elastic-jump/play/game/src)

**3. 较轻量的网页代码：RioBanida/Chinese-Garter**

[仓库](https://github.com/RioBanida/Chinese-Garter) · [主要玩法代码](https://github.com/RioBanida/Chinese-Garter/blob/master/chinese%20garter/www/js/chineseGarter.js)

项目使用 Phaser，包含跳跃速度、障碍变化、生命和得分逻辑，也带有 Cordova 项目配置。它适合研究简单的点击跳跃玩法，完整度和当前设备兼容性尚未运行验证，参考优先级低于前两项。

童年玩过 木头人和老狼老狼几点了游戏，介绍一下规则。然后根据规则，在网上寻找电子化的同类或者相似玩法。电脑或者移动端都行，最好有公开库可以参考

**木头人：常见有两种版本。**

- **原地定格版**：一人发令，其他人自由活动；喊完“一二三，木头人”立即保持姿势，不能动，有些地方还规定不能说话、不能笑。发令者可以做表情逗人，动了或笑了的人出局、换当发令者，具体处罚事先约定。[三联中读的童年玩法记录](https://mpre.lifeweek.com.cn/h5/article/detail?artId=7819)
- **向前接近版**：发令者站在远处，背对大家时，其他人向他靠近；发令者回头，所有人必须停止。被发现还在动，就退回起点或淘汰；先到终点或碰到发令者的人获胜。英文检索可以用 **Red Light, Green Light / Statues**。[Playworks 规则](https://www.playworks.org/game-library/red-light-green-light/)

因此，按键电子版可以还原“前进—停止—违规判定”，摄像头版则能保留真人“保持身体不动”的体验。

**老狼老狼几点了：核心是问答、接近、追捕和回家。**

1. 选一人当老狼，其他人当小羊，先划好安全线或“家”。
2. 小羊跟着老狼，反复问“老狼老狼几点了？”老狼回答普通时间时，继续跟随。
3. 老狼突然回答“十二点了！”——有些地方喊“天黑了”或“开饭了”——立即转身追人。
4. 小羊赶紧逃回安全区，回家后不能再被抓；被抓的人下一轮当狼，或按当地约定出局。

国内幼儿园教案中能看到“跟随老狼、十二点跑回家”的版本。[中文玩法示例](https://www.youshiok.com/video/2802)

还有一种**报几点就向前走几步**的版本：老狼站在远处背对大家，报“三点”就走三步，喊“开饭了”才转身追捕。英文通常叫 **What’s the Time, Mr Wolf? / What Time Is It, Mr Wolf?**。[英国童军规则](https://www.scouts.org.uk/activities/play-what-time-is-it-mr-wolf/)

**二、值得参考的电子版和公开库**

| 项目 | 平台与玩法 | 与现实规则的对应 | 源码情况 |
|---|---|---|---|
| **[木头人（Statues）](https://gitcode.com/code_2007/dora-Statues)** | 电脑／手机操作，仓库提供网页导出包；按住前进，松手停止，与 4 名 AI 竞速 | **高度接近“向前接近版”**：背对时跑、回头时停、违规退回起点、摸到发令者获胜；额外加入三次违规失败、技能等机制 | **完整项目，AGPL-3.0-only**；TypeScript＋Dora SSR |
| **[Squid Game / Red Light Green Light](https://0shuvo0.github.io/squidgame/)** | 电脑浏览器，同键盘双人，分别用 `↑` 和 `W` 前进 | **高度接近“向前接近版”**：观察者回头时移动判负，到终点成功；有时间限制 | [GitHub 源码](https://github.com/0shuvo0/squidgame)，JavaScript＋Three.js；未发现项目许可证 |

如果你的重点是**照着童年规则做自己的游戏**，最值得先看这三个源码：

- **中文完整项目：`dora-Statues`。** README 已列出 `Game/Rules.ts` 的规则参数和 `Game/World.ts` 的状态、违规与胜负判定，适合研究怎样把现实规则拆成程序逻辑。仓库也有 `木头人-web-html.zip`，作者提供了解压运行说明。[项目文档](https://gitcode.com/code_2007/dora-Statues)
- **简单网页原型：`0shuvo0/squidgame`。** 我查看了 `main.js`，能直接看到观察者转身、玩家速度、松键减速、违规检测和终点检测，适合学习最小实现。它目前用键盘控制，不能直接视为已适配手机触屏。[核心代码](https://github.com/0shuvo0/squidgame/blob/main/main.js)
- **真人体感方向：`showman-sharma/red-light-green-light`。** 适合参考摄像头如何判断“动了没有”；它采用简单运动检测，并非逐个识别人、分别判罚的完整裁判系统。[说明与源码](https://github.com/showman-sharma/red-light-green-light)

这里要区分：**公开仓库不一定有开源授权**。上述三个项目分别是 AGPL、未发现许可证、MIT；复用时按各自许可处理，素材另看授权。

**三、“老狼老狼几点了”的电子版，找到什么程度？**

**最明确的移动端案例是 [《Mr Wolf》——Reyn Interactive Limited](https://play.google.com/store/apps/details?id=com.reyninteractivelimited.mrwolf)，Android。**

开发者明确说明它改编自传统的 *What’s the Time, Mr Wolf?*，玩法是跟踪、靠近狼，**被狼看见正在移动时，它就会追你**。

它值得参考的地方是“接近危险角色—被发现—遭到追捕”的过程，但与传统规则有一个明显差别：

> 传统玩法由“十二点／开饭了”触发追捕；这个改编版由“被看见移动”触发追捕，更像木头人与老狼玩法的结合。

商店说明没有充分证明它包含“报时走步、逃回安全线、抓到后角色轮换”的完整流程，**本次也未找到它的公开源码**。

另有两个容易混淆的搜索结果：

- **[Teacher’s Pet：What Time Is It, Mr Wolf?](https://tpet.co.uk/mr-wolf)**：官方介绍重点是学习看钟、认识时间，不能仅凭名字把它当作传统追逐游戏的还原。
- **[Airemz/What-time-is-it-Mr-Wolf-](https://github.com/Airemz/What-time-is-it-Mr-Wolf-)**：虽然有源码，但我查看后发现主要是 C++ 双向链表模拟：按时间更新玩家坐标，在“午饭”事件中删除距离狼过近的玩家。它不是带场景、自由奔跑和实时追捕的可玩成品，不适合作为完整游戏底座。

**按你的用途，我建议优先研究 `dora-Statues` 的规则组织，再看 Three.js 项目的简洁实现。** 若制作“老狼老狼几点了”，还需补上它独有的流程：

`问时间 → 跟随／按报时前进 → 十二点或开饭 → 狼追捕 → 小羊逃回安全区 → 换角色`

这次核对的是项目文档、商店介绍及部分源码，未逐一安装试玩；其中**木头人已有可直接参考的完整公开项目，老狼的完整传统规则开源实现暂未确认找到**。
