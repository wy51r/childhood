# 木头人：停动判定与电子化参考

整理日期：2026-11-23｜对应 Q07｜两种现实版本分开记录

## 原始需求

“童年玩过 木头人和老狼老狼几点了游戏，介绍一下规则。然后根据规则，在网上寻找电子化的同类或者相似玩法。电脑或者移动端都行，最好有公开库可以参考”。

## 现实规则与变体

无需特殊道具，一人发令，其他人参与；原地版需要活动区域，接近版需要起点与终点。

- 原地定格版：口令结束后不能动，有的版本还不能笑或说话；发令者逗人但不触碰，失误者换角色或退出。依据：[三联中读玩法记录](https://mpre.lifeweek.com.cn/h5/article/detail?artId=7819)。
- 向前接近版：发令者背对时前进，回头后保持静止；被发现动了退回起点或淘汰；到终点／摸到发令者成功。依据：[Playworks Red Light, Green Light](https://www.playworks.org/game-library/red-light-green-light/)及本对话的规则整理。

“退回起点”“直接淘汰”“累计违规”应分别配置。回头的起止时刻、是否允许眨眼／自然晃动、是否追逐摸到者，属于待定变体。英语可搜 Red Light Green Light、Statues、Grandmother’s Footsteps；不要把所有变体自动视为同一规则。

0shuvo 的[试玩入口](https://0shuvo0.github.io/squidgame/)对应[main.js](https://github.com/0shuvo0/squidgame/blob/main/main.js)：两位玩家按 ↑ 和 W，代码有速度归零、观察者朝向、终点和超时判断；现有输入以键盘为主，不能直接视为已适配手机触控。建议重点读 Player.check、lookForward／lookBackward 和输入事件。

摄像头项目 README 明确：红灯检测到任何人移动就整局结束，不是逐个人识别出局。运行需 Python、requirements.txt 中依赖、摄像头及资源；本轮未执行安装。动动乐园是得分式定格，未还原跑向发令者的赛程。

## 开发参考（建议）

按键版：等待→背对可动→转身预警→观察禁动→违规／终点→下一轮。
摄像头版需单独定义移动阈值和噪声容忍；“角色速度不为零”和“真人画面变化”是两种不同裁判。
先决定原地还是接近版，再处理判定窗口、提示音与回头动画同步。不把《鱿鱼游戏》的生存包装当作传统玩法必需部分。

## 待确认与核验
