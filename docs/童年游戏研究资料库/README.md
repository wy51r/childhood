## 如何理解证据

- 用户确认：只对明确确认的规则成立，目前斗拐核心已确认；其余版本不要替用户决定。
- L0：历史线索、本轮未复核或正文不可读。
- L1：阅读官方介绍、商店说明、规则正文或 README；功能可能只是作者陈述。
- L2：检查目录或部分实现；不代表完整代码审计、可编译、无缺陷或联机正常。
- L3：实际安装运行。本资料库没有 L3。
- 仓库元数据：仅确认仓库、分支和 API 识别的许可信息，不等同逐文件源码检查。

“资料公开”“源码公开”“许可明确”分开记录。MIT／Apache／AGPL 等项目代码许可不能自动覆盖素材、字体、音乐或原生 App。

## 阅读时优先留意

1. 抓石子代码的“时机条＋自动动画”与自由抓石子操作不同。
2. 翻花绳的手势连线演示未实现真实绳圈和交接。
3. 跳皮筋要保留脚位和勾绕顺序，不等同跳过障碍。
4. 木头人停止移动与老狼突然追捕是不同主循环。
5. 跑马城的关键是成功／失败改变队伍人数，不只是破人墙。
6. 90 年代中原是目标背景；海外同类和其他地区资料须标为对照。

## 资料边界与后续维护

历史问答保存当时说法，当前结论以研究文档与修订清单为准。发布状态、下载入口、许可证可能变化；正式采用项目时重新检查并记录具体提交版本。
所有开发参考段落都是建议，尚未确定引擎、联网、画风、商业用途或最终规则。

本目录只包含研究摘要、用户与助手历史问答、链接和结构化索引；没有复制第三方游戏源码、图片、音视频或安装包。这样既能离线阅读整理结果，也能追溯原始资料。

以后新增项目时，先补案例记录与来源核验，再更新对应游戏文档；保留“不确定”状态直到得到证据，不用搜索不到代替不存在。
